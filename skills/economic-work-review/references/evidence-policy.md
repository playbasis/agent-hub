# Evidence policy

- **Cite what you read.** Every rationale names the commit hashes it relied on. If you couldn't read a commit (rewritten history, a missing repository), say so in `assumptions` and lower your confidence.
- **Different claims stay different.** "A test file exists", "the tests passed" and "the feature works end to end" are three claims. Commit messages and agent replies saying "done" or "works" aren't evidence that something works.
- **Links aren't authorship.** The Hub links commits to sessions by co-author trailers, shared files and timing. Treat those as where work and commits line up, not proof of who wrote what.
- **Never infer hands-on time.** How long agents ran, how many sessions ran in parallel and how many prompts were sent don't measure the person's time. Only the person records it.
- **No money.** Estimates are hours. The Hub applies the person's chosen rate and subscriptions.
- **Read-only.** Don't run the repository's code, change files, write to the Hub's ledger yourself, resume agent sessions or edit skills. Hand back JSON and let the person import it.
- **Stay local.** Don't send evidence, paths or commit contents to any service other than the model session the person is already using.
